# بنية المستودع والشيفرة

## خريطة المستودع

| المجلد أو الملف | محتواه |
|---|---|
| `addon_src/` | مصدر إضافة NVDA: برنامج تشغيل الصوت، ونوافذ الأدوات، ومسار النص العربي، وبرنامج راوي المساعد، وسكربت بناء الإضافة |
| `voices/` | الأصوات المرفقة بالإضافة (أصيل ورياض وإليز)، كل صوت بملفه الأساسي ورقعه |
| `lang/` | اللغة العربية لـRHVoice ومولّداتها |
| `lang_fr/` | اللغة الفرنسية لـRHVoice ومولّداتها |
| `engine/` | تعديلات فصيح على RHVoice (رقع ومصادر WORLD) والالتزام الذي بُنيت عليه |
| `unit/` | محرك الأصوات الممتازة (اختيار الوحدات) وأدوات تدريبها وتصغيرها، وسكربت بناء المحرك |
| `scripts/` | مراحل تدريب الأصوات المدمجة: استخراج الخصائص، والمحاذاة، والتسميات، والتدريب |
| `tools/` | أدوات مساعدة: مراحل التدريب الكاملة، والمعايرة، وصنع حزم الأصوات، وضبط الأصوات، والقياس |
| `third_party/` | ما يُحزَم من مشاريع أخرى: مكتبات RHVoice لويندوز، وBdl، وراوي، وبرق، وONNX Runtime |
| `tests/` | اختبارات مسار النص العربي والفرنسي والرقع والمحدِّد والتنزيل |
| `train_compact_voice.sh` | تدريب صوت مدمج بأمر واحد |
| `train_premium_voice.sh` | تدريب صوت ممتاز بأمر واحد |
| `TRAINING.md`، `BUILD-NOTES.md`، `unit/README.md`، `tools/VOICE-SETTINGS.md` | التوثيق الإنجليزي التفصيلي |
| `CHANGELOG.md` | سجلّ التغييرات لكل إصدار |

## الإضافة (`addon_src/`)

- `synthDrivers/fasih/__init__.py`: برنامج تشغيل الصوت. يحمّل مكتبة RHVoice (`RHVoice.dll` و`libRHVoice_core.dll`) عبر ctypes، ويعرّف إعدادات الصوت، ويقسّم النص حسب الكتابة، ويرسل كل جزء إلى الصوت المناسب، ويشغّل الصوت عبر مشغّل NVDA. فيه أيضًا كتابة ملفات الأصوات المدمجة عند تشغيل NVDA: كل صوت يأتي بملف أساسي `base.data` ورقع صغيرة، ويكتب البرنامج منها `voice.data` المطابق لإعدادات النَّفَس وإصلاح الحروف التي اخترتها (`_apply_quality` و`_write_voice`).
- `arabic_pipeline.py`: مسار النص العربي: تطبيع الأرقام والتواريخ والعملات، وقاموس النطق، والتشكيل، وعلامات همزة الوصل، والوقف، ودمج حركات المستخدم.
- `arabic/ar_tashkeel.py` و`arabic/ar_g2p.py`: وحدات عربية من ClaritySynth (التشكيل والتحويل من الحروف إلى الأصوات).
- `pbt/`: ما أخذته من مشروع rhvoice-arabic لكوكب المكفوفين التقني بمباركتهم: قاموس النطق الافتراضي، وقاموس المستخدم، وأسماء الرموز التعبيرية، وتطبيع النص، والمرشّح الصوتي.
- `loudness.py`: موازنة الارتفاع والمحدِّد الاستباقي.
- `rawi_host/`: البرنامج المساعد الذي يشغّل راوي خارج NVDA (مصدره بلغة C وملفه التنفيذي لويندوز).
- `globalPlugins/fasihVoices.py`: قائمة «فصيح» في أدوات NVDA: تنزيل الأصوات وتثبيتها (ومنها إعادة بناء جدول الوحدات للأصوات الممتازة عند التثبيت)، وقاموس النطق، وأداة تشكيل النصوص، والبحث عن التحديثات.
- `eq/` و`ms/`: مرشّحات النبرة ومرشّحات التعديل لكل صوت.
- `samples/`: عيّنات الأصوات التي تُسمع في نافذة التنزيل.
- `locale/`: ترجمة الواجهة (العربية).
- `doc/ar/readme.md`: صفحة المساعدة العربية داخل الإضافة.
- `build_release.sh`: يبني ملف الإضافة من المستودع وحده (انظر [البناء](07-building.md)).

## رحلة النص من NVDA إلى الصوت

1. يرسل NVDA إلى برنامج التشغيل سلسلة كلام: نصوص، وعلامات، وتغييرات لغة وطبقة.
2. يقسّم البرنامج النص إلى جمل ومجموعات، ثم حسب الكتابة: العربي في جهة، وغير العربي في جهة.
3. يمرّ الجزء العربي بمسار النص العربي: التطبيع، ثم قاموس النطق، ثم التشكيل بالمشكِّل المختار (راوي في برنامجه المساعد، أو برق داخل NVDA)، مع الإبقاء على حركات المستخدم، ثم قواعد الوقف والإعراب.
4. يرسل البرنامج كل جزء إلى RHVoice مع اسم الصوت (العربي أو الثانوي) وإعدادات السرعة والطبقة والارتفاع.
5. داخل RHVoice تحوّل قواعد اللغة النص إلى أصوات لغوية مع سياقها الكامل (تسميات HTS)، ثم يولّد الصوت المدمج أو الممتاز الموجة الصوتية (انظر [المحرك](05-engine.md)).
6. تعود الموجة إلى برنامج التشغيل قطعة قطعة، فيقصّ الصمت الأول، ويوازن الارتفاع، ويشغّلها فورًا، فيبدأ الكلام قبل أن تكتمل العبارة.

## اللغة العربية لـRHVoice (`lang/`)

لغة «بيانات فقط»: لا شيفرة فيها، بل قواعد foma وجداول يقرؤها RHVoice. يكتب `gen_foma.py` و`gen_rest.py` مصادر foma، ويترجمها `build_lang.sh` بأداة foma وبأداتي RHVoice `att2bin` و`dtree2bin`. تغطّي القواعد الشدّة، والحروف الشمسية والقمرية، وهمزة الوصل في الكلام المتصل، والتنوين، والتاء المربوطة، والمدود ومنها المخفية، والنبر الكلاسيكي، وأقسام الكلمات. ملف `labelling.xml` يحدّد خصائص السياق التي تراها النماذج.

اللغة الفرنسية (`lang_fr/`) مبنية بالطريقة نفسها حول معجم نطق من نحو 241 ألف كلمة، مع قواعد تهجئة للكلمات الغائبة عنه، والإدغام، والأرقام، والمقاطع، والنبر. ويحضّر `scripts/ar_prep.py` و`scripts/fr_prep.py` النص بالطريقة نفسها في التدريب وفي الإضافة.

## الاختبارات

`tests/test_arabic.py` يختبر الوقف، وهمزة الوصل، وحركات الوصل المساعدة، ودمج حركات المستخدم، وتقسيم النص حسب الكتابة، والمسار الكامل حين يتوفّر راوي. تشغيله:

```
python3 tests/test_arabic.py
```

اختبارات راوي الكاملة تحتاج أيضًا `RAWI_ORT_LIB` (مكتبة ONNX Runtime) و`FASIH_ADDON_DIR` (مجلد برنامج تشغيل مبني).
